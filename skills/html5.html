WEB DEVELOPMENT FUNDAMENTALS

Learn HTML5

HTML (HyperText Markup Language) defines the structure and meaning of content on a web page. It tells a browser which content is a heading, paragraph, image, link, form, or other element.

Think of a website as a building: HTML provides its structure, CSS handles its appearance, and JavaScript adds interactive behavior.

1. Where is HTML used?

  • Personal websites and portfolios.
  • School portals and education platforms such as TMH.
  • Online stores, dashboards and web applications.
  • Forms used for registration, search and data entry.

2. A basic HTML document

This example creates a small web page containing a heading, a paragraph and a link. 

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport"
        content="width=device-width, initial-scale=1.0">
  <title>My First Page</title>
</head>
<body>
  <h1>Welcome to My Website</h1>
  <p>I am learning HTML5.</p>
  <a href="https://example.com">Visit Example</a>
</body>
</html>

3. Important HTML elements

  • <h1> to <h6>: headings.
  • <p>: paragraphs.
  • <a>: links to pages and resources.
  • <img>: images, with meaningful alternative text.
  • <ul> and <li>: lists.
  • <form> and <input>: user input.
  • <header>, <nav>, <main> and <footer>: semantic page structure.

4. A practical example

A school portal might use HTML to display a student's report card. Headings identify the student and term, tables organize subject marks, and links provide access to other portal pages. 

<section aria-labelledby="results-title">
  <h2 id="results-title">Term Results</h2>
  <p>Student: Example Student</p>

  <table>
    <thead>
      <tr>
        <th scope="col">Subject</th>
        <th scope="col">Marks</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td>Mathematics</td>
        <td>85</td>
      </tr>
    </tbody>
  </table>
</section>

This is a static HTML example. In a real TMH application, Django would retrieve authorized student results from the database and render them into the page.

5. What should you practise?

  • Create a page with a title, heading and three paragraphs.
  • Add links to two other pages.
  • Create a table with three subjects and their marks.
  • Use semantic elements to organize the page.
