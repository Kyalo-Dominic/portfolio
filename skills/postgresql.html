DATABASES & DATA MANAGEMENT

Learn PostgreSQL

PostgreSQL is an open-source relational database management system. It stores structured information in tables and supports SQL queries, relationships, constraints, transactions and advanced data types.

Why PostgreSQL matters to you: A platform such as Top Mark Hub needs reliable storage for schools, users, enrollments, subjects, marks and academic results.

1. Where is PostgreSQL used?

  • Education systems and student information platforms.
  • Banking, fintech and transaction-processing applications.
  • Business applications, reporting and analytics.
  • Web backends built with Django and other frameworks.

2. Understanding tables

A table contains rows and columns. Each row represents a record, while each column describes an attribute of that record. 

CREATE TABLE subjects (
    id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    code VARCHAR(20) UNIQUE NOT NULL
);

In this example, the primary key identifies each subject, while the unique constraint prevents two subjects from sharing the same code.

3. Insert and retrieve data

SQL statements allow you to add, retrieve, update and delete records. These are basic examples using a sample table. 

INSERT INTO subjects (name, code)
VALUES ('Mathematics', 'MATH');

SELECT id, name, code
FROM subjects
ORDER BY name;

4. Filter and summarize data

The WHERE clause filters records. Aggregate functions such as AVG and COUNT summarize data. 

SELECT
    subject,
    AVG(mark) AS average_mark,
    COUNT(*) AS number_of_records
FROM exam_results
WHERE mark BETWEEN 0 AND 100
GROUP BY subject
ORDER BY average_mark DESC;

This query assumes that an exam_results table exists with suitable subject and mark columns. It calculates the average and number of records for each subject.

5. Relationships and foreign keys

Relational databases connect records through keys. A foreign key ensures that a referenced record exists in the related table. 

CREATE TABLE students (
    id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    full_name VARCHAR(150) NOT NULL
);

CREATE TABLE exam_results (
    id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    student_id BIGINT NOT NULL
        REFERENCES students(id),
    subject VARCHAR(100) NOT NULL,
    mark NUMERIC(5, 2)
        CHECK (mark BETWEEN 0 AND 100)
);

6. Transactions

A transaction groups database operations so that they can be committed together or rolled back if a problem occurs. 

BEGIN;

UPDATE accounts
SET balance = balance - 500
WHERE id = 1;

UPDATE accounts
SET balance = balance + 500
WHERE id = 2;

COMMIT;

This illustrates transaction syntax, not a complete money-transfer implementation. Real financial systems also need validation, sufficient-funds checks, concurrency controls and other safeguards.

7. PostgreSQL with Django

Django models describe application data, while PostgreSQL stores the resulting records. Django's ORM allows many database operations to be performed through Python. 

# Example Django ORM query
from academic.models import Subject

subjects = Subject.objects.order_by("name")

for subject in subjects:
    print(subject.name)
Connection to TMH: PostgreSQL can store academic records and support queries for report cards and performance analysis. Access controls, data validation, backups and careful migrations remain essential.

8. What should you practise?

  • Create a database and a table.
  • Insert sample records and retrieve them using SELECT.
  • Filter results using WHERE and sort them using ORDER BY.
  • Calculate averages using GROUP BY.
  • Create related tables using primary and foreign keys.
  • Connect a Django model to PostgreSQL and practise migrations.
