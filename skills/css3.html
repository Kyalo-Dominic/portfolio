WEB DESIGN & PRESENTATION

Learn CSS3

CSS (Cascading Style Sheets) controls how HTML content looks. It defines colors, typography, spacing, layouts, borders, responsive behavior and animations.

Remember: HTML defines the content, CSS presents it, and JavaScript adds behavior. Your portfolio uses all three.

1. Where is CSS used?

  • Designing responsive websites for phones and computers.
  • Building navigation bars, cards, forms and dashboards.
  • Creating themes, hover effects and animations.
  • Presenting information clearly in school and business portals.

2. Basic CSS syntax

A CSS rule selects an element and applies one or more declarations. Each declaration has a property and a value. 

h1 {
  color: #00e68a;
  font-size: 2.5rem;
  margin-bottom: 16px;
}

p {
  color: #a7b2c7;
  line-height: 1.7;
}

4. Responsive design

Responsive CSS adapts a page to different screen sizes. A media query lets you apply different styles when a condition is met. 

.projects-grid {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 20px;
}

@media (max-width: 700px) {
  .projects-grid {
    grid-template-columns: 1fr;
  }
}

On wider screens, this example creates three columns. On screens up to 700 pixels wide, it changes to one column.

5. Useful CSS concepts

  • color and background: text and surfaces.
  • margin and padding: outside and inside spacing.
  • display: flex: arranging items along a flexible axis.
  • display: grid: arranging items in rows and columns.
  • border-radius: rounding corners.
  • :hover: changing styles when a pointer is over an element.
  • @media: applying styles based on screen or device conditions.
  • transition and @keyframes: visual effects and animations.

6. A practical project

Try creating a responsive project card with a title, description and link. Give it a dark background, a subtle border and a hover effect. Then make the card fit narrow mobile screens. 

.project-card {
  padding: 24px;
  border: 1px solid #26334b;
  border-radius: 12px;
  background: #151e32;
  transition: transform 0.25s ease;
}

.project-card:hover {
  transform: translateY(-4px);
}
Connection to TMH: CSS can help make student dashboards, report cards, teacher forms and school administration pages easier to use on desktop and mobile devices.

7. What should you practise?

  • Change the colors and spacing of a simple HTML page.
  • Build a card with padding, borders and rounded corners.
  • Create a three-column grid that becomes one column on mobile.
  • Add a subtle hover transition.
