PROGRAMMING & DATA

Learn Python

Python is a general-purpose programming language known for its readable syntax and broad ecosystem. It is used in web development, automation, data analysis, scientific computing and AI.

Why Python matters to your work: You can use it for Django applications, data analysis, numerical methods and mathematical modelling.

1. Where is Python used?

  • Web backends using frameworks such as Django.
  • Data analysis with libraries such as pandas and NumPy.
  • Scientific and numerical computing.
  • Automation scripts and AI/machine-learning projects.

2. Variables and basic data types

Python variables refer to values. Common built-in types include integers, floating-point numbers, strings and Booleans. 

student_name = "Amina"
maths_mark = 85
average = 78.5
passed = True

print(student_name)
print(maths_mark)

3. Conditions and loops

Conditions let a program make decisions. Loops repeat instructions over a sequence or while a condition remains true. 

mark = 72

if mark >= 50:
    print("Pass")
else:
    print("Needs improvement")

for subject in ["Maths", "Physics", "Computer Science"]:
    print(subject)

4. Functions

Functions package logic into reusable units. They can receive arguments and return a result. 

def calculate_average(marks):
    if not marks:
        return None

    return sum(marks) / len(marks)

scores = [75, 80, 90]
print(calculate_average(scores))

5. Practical example: analyse student marks

This short program calculates the mean mark and counts how many students achieved at least 50. It is a simple illustration of the kind of analysis an education platform might perform. 

marks = [64, 81, 47, 73, 90, 55]

class_average = sum(marks) / len(marks)
pass_count = sum(mark >= 50 for mark in marks)

print(f"Class average: {class_average:.1f}")
print(f"Students scoring 50 or above: {pass_count}")

6. Python for mathematics and computing

  • NumPy: arrays, matrix operations and numerical calculations.
  • pandas: tabular data, cleaning and statistical summaries.
  • Matplotlib: plots and data visualizations.
  • SciPy: scientific algorithms, optimization and numerical methods.
