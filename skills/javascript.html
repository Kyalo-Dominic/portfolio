INTERACTIVE WEB DEVELOPMENT

Learn JavaScript

JavaScript is a programming language that allows web pages to respond to user actions, update content, validate forms and communicate with web services.

HTML provides structure, CSS controls appearance, and JavaScript adds behavior. The mobile menu on this portfolio uses JavaScript to open and close the sidebar.

1. Where is JavaScript used?

  • Interactive menus, tabs, sliders and forms.
  • Live search and client-side input validation.
  • Dashboards that update when data changes.
  • Browser applications that communicate with APIs.

2. Variables and data

Use const for bindings that will not be reassigned and let when reassignment is needed. 

const studentName = "Amina";
let marks = 72;

marks = 85;

console.log(studentName);
console.log(marks);

3. Functions

Functions group reusable instructions. They can accept inputs and return results. 

function calculateAverage(total, subjects) {
  if (subjects <= 0) {
    return null;
  }

  return total / subjects;
}

const average = calculateAverage(360, 6);
console.log(average); // 60

4. Responding to events

An event listener runs a function when something happens, such as a button click.

Interactive demonstration

Click the button to change this message.

const button = document.querySelector("#demo-button");
const message = document.querySelector("#demo-message");

button.addEventListener("click", () => {
  message.textContent = "JavaScript responded to your click!";
});

5. DOM manipulation

The Document Object Model (DOM) represents a page as objects that JavaScript can select and modify. 

const heading = document.querySelector("h1");

heading.textContent = "Welcome to My Website";

6. A practical example

A school portal might use JavaScript to validate a form before submission or update a marks total as a teacher enters scores. Important validation and permissions must still be enforced by the server, not JavaScript alone. 

const scores = [75, 80, 90];

const total = scores.reduce(
  (sum, score) => sum + score,
  0
);

const average = total / scores.length;

console.log("Total:", total);
console.log("Average:", average);

7. What should you practise?

  • Write a function that adds two numbers.
  • Make a button change a paragraph's text.
  • Calculate the average of a list of marks.
  • Use the browser developer console to inspect errors.
