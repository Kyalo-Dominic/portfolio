PYTHON WEB DEVELOPMENT

Learn Django

Django is a high-level Python web framework for building database-driven websites and web applications. It provides tools for URL routing, database models, templates, forms, authentication and an administration interface.

Why Django matters to you: It is part of the technology stack you are using to build Top Mark Hub, including its users, schools, academic records and reporting features.

1. Where is Django used?

  • Education portals and school management systems.
  • Business dashboards and database-driven applications.
  • Authentication, forms and role-based user interfaces.
  • Websites that need maintainable Python backends.

2. The request-response cycle

A browser requests a URL. Django matches it to a URL pattern, calls a view, and returns a response—often by rendering a template with data retrieved from a database.

3. A simple Django view

A view receives an HTTP request and returns an HTTP response. For example, this view returns a short message. 

# views.py
from django.http import HttpResponse

def home(request):
    return HttpResponse("Welcome to my Django application!")

4. Connect a URL to the view

URL patterns tell Django which view should handle a request. In a project's URL configuration, you can connect the root URL to the view above. 

# urls.py
from django.urls import path
from . import views

urlpatterns = [
    path("", views.home, name="home"),
]

5. Models and databases

Django models describe the data your application stores. Django can generate database tables through migrations when your models change. 

# models.py — simplified example
from django.db import models

class Subject(models.Model):
    name = models.CharField(max_length=100)
    code = models.CharField(max_length=20, unique=True)

    def __str__(self):
        return self.name

After creating or changing models, developers normally run python manage.py makemigrations and python manage.py migrate to prepare and apply schema changes.

6. Templates

Templates combine HTML with data supplied by a view. Django's template language can display values and repeat elements. 

<h1>Welcome, {{ student_name }}</h1>

<ul>
  {% for subject in subjects %}
    <li>{{ subject }}</li>
  {% empty %}
    <li>No subjects available.</li>
  {% endfor %}
</ul>

7. Security essentials

  • Use Django's authentication and permission systems appropriately.
  • Validate inputs on the server and protect forms against CSRF.
  • Keep secret keys, database passwords and API credentials out of public repositories.
  • Restrict access to records according to the user's role and permissions.
  • Use HTTPS and secure deployment settings in production.
Connection to TMH: Django can manage school and student records, authenticate teachers and administrators, and generate report cards. Each user's access must be checked on the server; hiding a button in HTML is not sufficient security.

8. What should you practise?

  • Create a Django project and a simple application.
  • Build a view and connect it through a URL pattern.
  • Create a model and apply its migrations.
  • Render a template using data passed from a view.
  • Practise authentication and role-based permissions.
